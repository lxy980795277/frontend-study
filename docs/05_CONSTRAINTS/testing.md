# 测试规范

全项目统一使用 Vitest，不引入 Jest。

## 目录

单元测试紧邻源码，放在 `__tests__/` 中，命名为 `*.spec.ts` 或 `*.spec.tsx`。

## 强制范围

后端：

- 包含业务判断的 Service
- Guard、Interceptor、Filter
- 配置解析
- 工具函数
- 基础设施失败分支

前端：

- Lab 核心算法
- Store
- 复杂 Hook
- Utils
- 数据转换

普通展示组件不强制单测，由 Playwright 覆盖。

## 覆盖率目标

| 范围             | 行  | 分支 | 函数 |
| ---------------- | --- | ---- | ---- |
| 后端业务 Service | 60% | 50%  | 70%  |
| 前端算法和 Utils | 80% | 70%  | 90%  |

## 规则

- 修复 Bug 先写失败测试。
- 测试不得访问生产数据库或 Redis。
- CI 使用隔离测试基础设施或 Mock。
- 禁止在测试日志和快照中输出真实环境变量。
