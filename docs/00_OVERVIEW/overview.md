# 项目概览

AI Frontend Engineering Lab 是面向 AI 应用时代的前端高阶工程实验平台。

项目使用全栈 Monorepo，让每个前端难点都能同时覆盖浏览器、框架、协议、后端和基础设施，并通过可交互页面、测试、指标和技术文档形成完整交付。
