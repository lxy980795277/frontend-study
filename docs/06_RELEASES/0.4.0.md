# 0.4.0 · Markdown Isolated Benchmark

发布日期：2026-07-28

## 新增功能

- 为 Markdown 流式增量渲染 Lab 增加“同步对比”和“隔离基准”双模式，使用 URL Query 保留模式状态。
- 增加单 Renderer 串行执行计划；奇数轮按 `Legacy → Incremental`、偶数轮按
  `Incremental → Legacy` 交替运行。
- 隔离基准不执行额外预热，配置 2 轮时仅产生 4 次正式执行，所有结果均进入报告。
- 每次测量先建立相同的 10 倍重型 Markdown 基线，再在已有大文档上分批追加确定性续写。
- 增加可停止的运行状态机、执行间卸载、浏览器稳定等待和异步任务取消。

## 性能观测

- 增加输入帧到实际 DOM Commit 的端到端延迟，并汇总平均值、P50、P95 和最大值。
- 增加 Main Thread、Wall Time、Long Task、DOM Commit、Worker Request 和 Coalesced Frame 指标。
- 增加 Legacy 与 Incremental 汇总卡片、逐轮执行明细、最终可见文本一致性校验和 JSON 导出。
- 同步对比指标明确标记为共存负载，不再解释为单个 Renderer 的独立性能。

## 工程质量

- 为执行计划、模式解析、统计聚合、内容摘要和报告生成补充 Vitest 测试。
- 为 Legacy 与 Incremental 增加统一的 DOM Commit 通知，最终完成点不再依赖 Streamer 发送结束。
- XSS Fixture 使用内联安全资源，避免无效图片请求产生控制台噪声。
- 同步 Web 架构、Lab Spec/Technical/Verify、测试约束、用户指南和技术经验。
