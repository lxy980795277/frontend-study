# 0.5.1 · Dependency Integration

发布日期：2026-07-31

## 依赖升级

- 将 GitHub Actions Checkout、Setup Node 和 pnpm Action 升级到 Dependabot 建议版本。
- 升级 Prisma Client/CLI 7.9.1、UUID 14、Lucide 1.27 和 Radix UI 补丁版本。
- 升级 Playwright、jsdom、PostCSS、lint-staged、Turbo 等开发工具。

## 兼容性处理

- 根据项目 Node 24 Engine，将 `@types/node` 保持在最新 Node 24 类型线。
- 根据最新版 `typescript-eslint` 的 Peer Range，将 TypeScript 保持在 6.0 兼容线。
- 根据最新版 `eslint-plugin-react` 的 Peer Range，将 ESLint 与 `@eslint/js` 保持在 9.39 兼容线。
- 重新生成 pnpm Lockfile，并对全部工作区执行严格 Peer 检查。

## 验证

- 依赖安装使用 Node.js 24.11.0 与 pnpm 11.16.0。
- `pnpm peers check`、完整 `pnpm check` 和分支合并状态检查通过。
