# 0.2.0 · Agent Stream Recovery

发布日期：2026-07-24

## 新增功能

- 增加 Agent 流式断线恢复 Lab，以统一 `/api/agent/stream` 接口覆盖新建、续传和刷新恢复。
- 使用 AG-UI 事件、SSE `Last-Event-ID` 与 Redis Stream 实现游标续传、事件重放和前端幂等去重。
- 增加 Thread、Agent Run 和 Message 持久化模型、Prisma Migration 与会话历史接口。
- 增加模拟 Agent Producer、Tool Call、随机文本分片、主动终止和可控故障注入。
- 增加连接状态、协议事件、故障和重复事件统计等可观测面板。
- 增加公共 HTTP/SSE 请求层和安全的 Markdown/GFM 渲染组件。

## 前端体验

- Labs 改为无侧边栏的卡片入口，Lab 详情页统一提供“返回 Labs”。
- Labs 首页增加透明手绘插画，并使用最大宽度和四列卡片网格承载后续模块。
- Home 页面迁移到 `/home`，根路径 `/` 服务端重定向到 `/home`。
- Home 私有实现收敛到 `src/home`，Lab 私有实现收敛到 `src/labs/<slug>`。
- 长对话只滚动消息区，输入框保持可见；Inspector 页签内容撑满剩余高度。

## 工程治理

- 普通 React 组件统一使用 `<component-name>/index.tsx`，测试跟随组件目录。
- 前端 Service 和 Store 移除 NestJS 风格的 `.service`、`.store` 后缀。
- 增加 `pnpm check:structure`，并接入根级自检和 CI。
- CI 增加 Prisma Migration 部署步骤。
- 补充 Agent Stream API、架构决策、技术设计、验证记录和用户指南。

## 验证

- Server：10 个测试文件、22 个测试通过。
- Web：5 个测试文件、17 个测试通过。
- Playwright：6 个端到端场景通过。
- 格式、Lint、结构检查、TypeScript、Next.js/NestJS 生产构建和 Knip 全部通过。
- 覆盖断线后手动重连、刷新恢复、事件去重、Producer Failure、主动 Abort 和 `/ → /home`。
