# 0.4.1 · Markdown Production Benchmark

发布日期：2026-07-29

## 改进优化

- 为 Markdown 隔离基准增加 10 轮配置，可生成 Legacy 与 Incremental 各 10 个正式样本。
- 使用 Production Build、综合重型 Fixture、47.3 万字符基线和 60 FPS 推送完成无预热基准。
- 归档完整原始 JSON 和正式性能报告，记录运行环境、参数、逐轮数据、聚合指标和适用边界。

## 性能结论

- Incremental 相比 Legacy 的主线程累计耗时降低 96.41%，加速 27.85 倍。
- 端到端平均完成时间降低 58.51%，加速 2.41 倍。
- DOM Commit P50 降低 31.16%，P95 降低 25.58%。
- 20 次执行的最终可见内容一致，Incremental Runtime Fallback 为 0。
- Long Task 总量未呈现稳定优势，因此不将其纳入性能提升结论。

## 工程质量

- 为 10 轮执行计划补充 Vitest 覆盖，验证 20 次执行数量与最终轮次顺序。
- 同步 Markdown Lab Spec、Technical、Verify、用户指南和历史验收状态。
- Web 18 个测试文件、50 条测试通过；Server 10 个测试文件、22 条测试通过。
- Structure、Format、Lint、TypeScript、Production Build、Knip 和浏览器控制台检查全部通过。
