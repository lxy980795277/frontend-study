# 0.1.0 · Project Foundation

发布日期：2026-07-23

## 新增功能

- 建立 pnpm Workspace 与 Turborepo 全栈 Monorepo。
- 建立 Next.js、React、Tailwind CSS、shadcn/ui、Lucide 与 Zustand 前端平台。
- 建立独立 Home 和 Labs 工作区，提供桌面侧边栏与移动端模块导航。
- 建立 NestJS、Prisma、MySQL 与 node-redis 后端基础设施。
- 增加健康探测接口、Next.js API 代理与 Swagger 文档。
- 增加前后端共享健康状态契约。

## 工程能力

- 建立共享 ESLint、TypeScript、Prettier、Commitlint 与 Knip 配置。
- 建立 Vitest、MSW、Playwright、Husky、lint-staged 和 GitHub Actions 质量门禁。
- 建立 Spec、架构、约束、验证、发布与协作完整文档体系。
- 使用 Redis DB 1 与 `frontend-study:` 前缀实现项目隔离。

## 验证

- 14 个单元测试与 2 个 Playwright 端到端测试通过。
- 格式、Lint、类型、生产构建和 Knip 检查通过。
- Home、Labs、健康代理和 Swagger HTTP Smoke Test 通过。
- MySQL `SELECT 1` 与 Redis `PING` 真实连接验证通过。

## 运行要求

- Node.js 24 LTS
- pnpm 11
