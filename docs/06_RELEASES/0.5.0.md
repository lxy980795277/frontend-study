# 0.5.0 · Large Data Grid

发布日期：2026-07-31

## 新增功能

- 新增独立的 Large Data Grid Lab，默认验证 1,000,000 行 × 100 列，共 100,000,000 个逻辑单元格。
- 提供纯 HTML DOM 双向虚拟化、主线程 Canvas 和 Worker OffscreenCanvas 三种 Renderer。
- 支持百万行分段滚动、快速跳转、键盘导航、稳定 Row ID 选择、范围复制、列宽调整、排序和过滤。
- 增加 Worker 故障注入与 Main Canvas 安全降级，保留当前逻辑位置、查询和选择语义。
- 增加三 Renderer 单实例隔离 Benchmark、固定滚动轨迹、逐轮报告、一致性摘要和 JSON 导出。

## 前端治理

- 将 Agent、Markdown 和 Large Data Grid 的领域类型统一迁入各 Lab 根级 `types/`。
- 按 Chat、Inspector、Compare、Benchmark、Workbench、Renderer 和 Overlay 重组组件拥有关系。
- 前端运行时函数统一为具有块级函数体和显式返回的箭头函数，并通过 ESLint 与 Structure Check 防止回退。
- 清理能够由类型、构造过程和循环边界证明冗余的内部兜底，同时保留网络、Worker、浏览器能力和资源生命周期边界。
- 为关键算法、异步协议、恢复策略和资源释放补充设计原因说明。

## 体验优化

- Labs 入口的已完成卡片不再展示难度、完成状态和额外入口文案。
- 构建中模块只展示“开发中”，卡片 Hover 改为支持 reduced-motion 的柔和缓出动效。
