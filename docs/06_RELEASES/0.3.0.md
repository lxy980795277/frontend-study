# 0.3.0 · Markdown Stream Rendering

发布日期：2026-07-27

## 新增功能

- 增加 Markdown 流式增量渲染 Lab，以相同确定性 Stream Frame 对比 Legacy 全量渲染和 Incremental 最小
  DOM Patch。
- 增加共享 Web Worker、Renderer 隔离、Single-flight、Confirmed/Pending Revision 和三类 Patch 协议。
- 增加 Worker Error、Message Error、请求超时和 DOM Apply 冲突后的安全 Full Render Fallback。
- 增加 DOMPurify 安全边界，以及代码块复制/折叠和表格 TSV 复制工具。
- 增加主线程、Worker、Patch、React Mount、帧合并和运行时降级指标。

## 超大基准与体验

- 增加约 4.7 万字符的真实 LLM 技术回答 Fixture，包含两个分别超过 300 行的代码块。
- 浏览器运行时将单一 Fixture 固定复制 10 份，形成约 47 万字符基线，避免在仓库维护重复数据。
- 基线经 Incremental Commit 明确确认后才开放尾部流式续写，初始化成本不污染续写指标。
- 增加 Loading、Error、Retry、Preparing、Ready、Running、Paused 和 Completed 状态。
- 增加 5–60 FPS 推送速度、字符/Token 切分、1×/4× 实例和 Worker 故障注入控制。
- 每个 Renderer 独立自动跟随底部；用户向上阅读时暂停，回到底部后恢复。
- 超长代码块限制在 22rem 内部双向滚动，桌面和移动端均不产生页面横向溢出。

## 工程质量

- 新增 `markdown-it`、DOMPurify、Radix Select/Slider 和对应类型依赖。
- 增加 Block Diff、Patch、Revision、Sanitize、Streamer、Benchmark Loader、指标和滚动 Hook 单元测试。
- 增加超大基线、错误重试、内容一致性、XSS、Worker Fallback、响应式和滚动行为 Playwright 测试。
- 同步 Web 架构、设计规范、Lab Spec/Technical/Verify、用户指南和架构决策。

## 已知口径

- 当前双栏指标描述 Legacy 与 Incremental 同时运行时的共存负载；两栏会竞争主线程、布局和绘制资源，不能作为
  任一方案独立运行时的无干扰性能结论。
- 后续将增加串行隔离 Benchmark；当前双栏主要用于内容一致性、Patch 行为、交互和共存压力观察。
