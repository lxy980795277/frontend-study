# 用户指南

## 首页

访问 `/` 会自动跳转到 `/home`。首页用于了解项目定位、查看系统连接状态，并进入 Labs 工作台。首页不展示实验模块侧边栏。

## Labs

Labs 是所有实验模块的统一入口，只展示模块卡片。选择卡片即可进入对应的独立实验页面；已完成模块不展示额外状态，
仍在构建的模块显示“开发中”。

每个 Lab 是无平台侧边栏的独立页面，右上角统一提供“返回 Labs”；页面包含可交互实验、状态观测、异常模拟和技术说明，
不与其他 Lab 共享业务逻辑。

## Agent 流式断线恢复

进入 `/labs/agent-stream-recovery` 后：

1. 输入纯文本并发送，首次发送会自动创建 Thread。
2. 对话区展示增量回复；右侧可以查看连接阶段、Run ID、Last-Event-ID、重连次数和 AG-UI 事件。
3. 标题区依次提供“新会话”“会话历史”“模拟断线/模拟重连”和“手动重试”。
4. Mock Agent 默认生成长篇回复和 Tool Call，后端每 20ms 推送一个随机长度文本分片。
5. “故障”页签只保留指定 Producer 失败点，用于观察 `RUN_ERROR` 收敛。
6. “停止运行”会请求服务端终止 Run，并等待标准终态。
7. “会话历史”从 MySQL 读取历史 Thread；页面刷新时会通过 URL 和历史接口自动恢复活跃 Run。
8. 点击“模拟断线”后页面保持断线态，Producer 继续运行；只有点击“模拟重连”才携带最后游标恢复消费。

该 Lab 不把消息、Run 或游标写入 localStorage/sessionStorage。

## Markdown 流式增量渲染

进入 `/labs/markdown-stream-rendering` 后：

1. 页面顶部提供“同步对比”和“隔离基准”，模式写入 `mode` Query，刷新和分享链接后仍进入相同模式。
2. 页面先加载一份真实 LLM 长回答并在浏览器内复制 10 份；基线准备完成后才允许启动。
3. 同步对比让 Legacy 与 Incremental 同时接收相同确定性续写，用于结果一致性、Patch、降级、滚动和共存压力验证。
4. 同步对比的指标标记为“共存负载”；任一侧的长任务都会影响另一侧，因此不用于解释单个实现的独立性能。
5. 同步模式的“场景”可切换长文本、内联结构、代码块、表格、综合重型与 XSS 安全续写；速度只改变调度频率，
   字符/Token 会改变确定性切分。
6. “1×/4×”用于观察多实例压力；“注入 Worker 故障”用于验证 Incremental 安全降级，重置后重新启用 Worker。
7. “指标”展示主线程与 Worker/Patch 分项，“Patch”展示 Request/Revision/操作，“运行时”展示实例阶段和降级原因。
8. 隔离基准任意时刻只挂载一个 Renderer，不执行预热，直接按
   `第 1 轮 Legacy→Incremental、第 2 轮 Incremental→Legacy` 的顺序交替测量；提供 `1 / 2 / 3 / 5 / 10`
   轮配置，总执行数等于轮次的两倍。
9. 隔离基准运行期间锁定模式和配置，只保留“停止”；停止后卸载 Renderer，并生成标记为未完成的诊断报告。
10. 完整报告展示主线程耗时、Commit 延迟 P50/P95/最大值、总运行时间、Long Task、Worker Request、
    Coalesced Frame、逐轮结果和最终可见内容一致性，可导出 JSON。
11. 代码块提供复制与折叠，300 行以上代码块在固定最大高度内独立滚动；表格可复制为 TSV，所有 HTML
    写入前都经过 DOMPurify。
12. 同步对比的两个 Renderer 默认跟随增量输出；向上滚动后暂停跟随，重新到底部后恢复。
13. 静态基准加载失败时页面显示可重试错误，禁止在空基线上启动测试。

## 大数据表格离屏渲染

进入 `/labs/large-data-grid` 后：

1. 工作台默认展示 1,000,000 行 × 100 列，共 100,000,000 个逻辑单元格，不会在主线程创建完整单元格矩阵。
2. Renderer 可切换 DOM Virtual、Main Canvas 和 Worker Offscreen；三种模式共享相同数据、几何和选择语义。
3. Grid 支持原生滚动、百万行跳转、方向键导航、Shift 扩选、列宽调整和受限 TSV 复制。
4. 排序和过滤在 Worker 中执行 Latest-Wins 查询；过期结果不会覆盖当前视图，空结果具有独立状态。
5. 高级设置可以调整数据规模、列数、Overscan、排序、过滤并注入 Worker 故障。
6. Worker Offscreen 不支持或运行失败时会切换到新的 Main Canvas，并在状态栏显示实际 Renderer 和降级原因。
7. 通过 `?mode=benchmark` 进入隔离基准；任意时刻只挂载一个 Renderer，完成后展示逐轮指标、一致性和 JSON 导出。
8. 窄屏下操作栏、指标和 Benchmark 报告在自身区域滚动，Grid 保持独立横纵滚动。
