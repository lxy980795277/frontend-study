# 用户指南

## 首页

访问 `/` 会自动跳转到 `/home`。首页用于了解项目定位、查看系统连接状态，并进入 Labs 工作台。首页不展示实验模块侧边栏。

## Labs

Labs 是所有实验模块的统一入口，只展示模块卡片。选择卡片即可进入对应的独立实验页面。

每个 Lab 是无平台侧边栏的独立页面，右上角统一提供“返回 Labs”；页面包含可交互实验、状态观测、异常模拟和技术说明，
不与其他 Lab 共享业务逻辑。

## Agent 流式断线恢复

进入 `/labs/agent-stream-recovery` 后：

1. 输入纯文本并发送，首次发送会自动创建 Thread。
2. 对话区展示增量回复；右侧可以查看连接阶段、Run ID、Last-Event-ID、重连次数和 AG-UI 事件。
3. 标题区依次提供“新会话”“会话历史”“模拟断线/模拟重连”和“手动重试”。
4. Mock Agent 默认生成长篇回复和 Tool Call，后端每 20ms 推送一个随机长度文本分片。
5. “故障”页签只保留指定 Producer 失败点，用于观察 `RUN_ERROR` 收敛。
6. “停止运行”会请求服务端终止 Run，并等待标准终态。
7. “会话历史”从 MySQL 读取历史 Thread；页面刷新时会通过 URL 和历史接口自动恢复活跃 Run。
8. 点击“模拟断线”后页面保持断线态，Producer 继续运行；只有点击“模拟重连”才携带最后游标恢复消费。

该 Lab 不把消息、Run 或游标写入 localStorage/sessionStorage。

## Markdown 流式增量渲染

进入 `/labs/markdown-stream-rendering` 后：

1. 页面先加载一份真实 LLM 长回答并在浏览器内复制 10 份；Legacy 与 Incremental 都确认相同超大基线后，“开始”才可用。
2. 基线阶段不计入性能指标；开始后两栏接收完全相同的确定性尾部续写，分别展示全量渲染和 Worker 增量 Patch 结果。
3. “场景”可以切换长文本、内联结构、代码块、表格、综合重型与 XSS 安全续写。
4. “推送速度”只调整播放调度速度，不改变同一场景的 Chunk 边界；“字符/Token”切换会重新确认基线。
5. “1×/4×”用于观察单实例和多实例压力；所有增量实例共享 Worker，但拥有独立 Revision 基线。
6. “注入 Worker 故障”会使增量 Runtime 自动切换为安全全量渲染，重置后重新启用 Worker。
7. “指标”只对比续写阶段的同口径主线程耗时，同时单独展示 Worker Parse/Diff、Patch Apply、React Mount 和降级统计。
8. “Patch”展示 Request、Revision、操作类型和块位置；“运行时”展示每个实例的阶段、已提交字符数与降级原因。
9. 代码块提供复制与折叠，300 行以上代码块在固定最大高度内独立滚动；表格可复制为 TSV，所有 HTML
   写入前都经过 DOMPurify。
10. 桌面端长内容只在 Renderer 和观测面板内部滚动；移动端纵向排列，代码和宽表格不会撑宽页面。
11. 两个 Renderer 默认随增量输出滚到底部；向上滚动查看历史时该实例暂停跟随，重新滚到底部后自动恢复。
12. 静态基准加载失败时页面显示可重试错误，禁止在空基线上启动测试。
